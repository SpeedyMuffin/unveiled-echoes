Privacy Policy

Last Updated: September 19, 2026

1. Overview

This Privacy Policy explains how the Pantheon Studio application handles data when interacting with Google APIs and YouTube services.

2. Information We Access and Use

Our application uses Google OAuth 2.0 to access the YouTube Data API solely for uploading automated video content (YouTube Shorts) and monitoring channel milestones for @pantheonoftheforgotten.

  • YouTube Upload: We upload video files, custom thumbnails, titles, descriptions, tags, and pinned debate questions directly to our authorized channel.
  • YouTube Read-Only: We retrieve public view counts, subscriber milestones, and public channel metrics to monitor series performance.

3. Data Storage and Security

All authentication credentials (OAuth tokens) are encrypted and stored locally within our dedicated server environment. We do not sell, transfer, or share any user or channel credentials with third parties.

4. Google API Services User Data Policy

Our use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

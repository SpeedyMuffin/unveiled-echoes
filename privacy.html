Privacy Policy

Last Updated: September 19, 2026

1. Overview

This Privacy Policy explains how the Unveiled Echoes Uploader internal application handles data when interacting with Google APIs and YouTube services.

2. Information We Access and Use

Our application uses Google OAuth 2.0 to access the YouTube Data API for the sole purpose of uploading automated video content (YouTube Shorts) and monitoring video performance metrics for the channel @TheUnveiledEchoes.

  • YouTube Upload: We upload video files, titles, descriptions, and tags directly to our authenticated channel.
  • YouTube Read-Only: We retrieve public view counts, like counts, and subscriber milestones to monitor channel progress.

3. Data Storage and Security

We do not collect, sell, or share any personal user data. OAuth authentication tokens (access and refresh tokens) are securely stored on our dedicated private server and are never exposed or transmitted to any third party.

4. Google API Services User Data Policy Compliance

Unveiled Echoes Uploader strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements. We do not use Google user data for advertising, machine learning model training without explicit consent, or any unauthorized external purposes.

5. Revoking Access

You can revoke access to your Google account permissions at any time via the Google Account Security Settings.
